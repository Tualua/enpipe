<objective>
Add a `--out-dir DIR` CLI flag to `enpipe encode` and `enpipe run` (and both
directory-input batch branches). `--out-dir` creates `DIR` on demand (`mkdir -p`)
and places the output inside as `<video-stem>.Encoded<video-suffix>` — the exact
formula already used by `resolve_output_path` for an *existing* directory. `--out`
stays strictly a file path (unchanged, byte-identical). `--out` and `--out-dir`
are mutually exclusive (manual `die()` guard).

Purpose: today `resolve_output_path` only puts output inside a directory that
already exists. The missing piece is folder creation when the directory does not
exist yet — plus a clean way to disambiguate "output is a folder" from "output is
a file" for a non-existent path.

Output: new `--out-dir` option wired through 4 code paths (encode single, encode
batch, run single, run batch), a single reusable `_ensure_out_dir(args)` helper
that does the wrapped `mkdir`, and fast hardware-free unit tests.
</objective>

**1. `_ensure_out_dir` helper in `encoding/pipeline.py`** (module level, after
`resolve_output_path`). Signature `def _ensure_out_dir(args) -> Optional[Path]:`.
Read `out_dir = getattr(args, "out_dir", None)` (defensive — hand-built test
Namespaces may lack it). If `out_dir is None`, return `args.out` unchanged (fallback
preserves `--out`/default byte-identity). Otherwise `out_dir.mkdir(parents=True,
exist_ok=True)` wrapped in `try/except OSError as ex:` → `die(f"не удалось создать
папку вывода {out_dir}: {ex}")`, then `return out_dir`. Russian docstring must note:
one `except OSError` covers both `PermissionError` (read-only/wrong-uid /data mount —
see .planning/debug/) and `FileExistsError` (path is an existing non-dir file); die()
on the main thread, never a raw traceback. Keep `resolve_output_path` itself PURE and
UNCHANGED (its 4 tests must stay byte-identical). Do not add a mutating variant.

**2. Mutual-exclusion guard.** At the top of `run_encode` right after the
which-preflight loop, and at the top of `run_pipeline` right after its which-loop, add:
`if args.out is not None and getattr(args, "out_dir", None) is not None: die("-o/--out
и --out-dir взаимоисключающи: задайте только один")`. This single main-thread guard
protects every entry path (direct encode, run single, both batch branches) because it
sits above the is_dir() branch. Do NOT use argparse `add_mutually_exclusive_group` —
it prints a differently-formatted `usage:` error and never fires for the hand-built
Namespace in `_pipeline_one` (per RESEARCH Point 1).

**3. Encode single-file path** (`pipeline.py`, the `resolve_output_path(args.video,
args.out)` call, currently ~line 134): replace `args.out` argument with
`out_base = _ensure_out_dir(args)` then `out = resolve_output_path(args.video,
out_base)`. After mkdir, `out_base.is_dir()` is True so the existing dir-branch of
resolve_output_path returns `<dir>/<stem>.Encoded<suffix>` with zero function changes.

**4. Encode batch branch** (`pipeline.py`): keep the existing `if args.out is not None
and not args.out.is_dir(): die(...)` guard; extend its message to mention `--out-dir`
for a non-existent folder. After the guard block (before building `process_one`/
`should_skip`), compute `out_base = _ensure_out_dir(args)` once so the folder is
created up front. Change the `should_skip` closure's `resolve_output_path(v, args.out)`
to `resolve_output_path(v, out_base)`. `process_one`'s `Namespace(**{**vars(args),...})`
already copies `out_dir` — no change needed; the per-file `run_encode` recursion re-runs
mkdir idempotently (`exist_ok=True`).

**5. `cli/main.py` argparse.** Add `--out-dir` to BOTH `encode_p` (after its `-o/--out`
block) and `run_p` (after its `-o/--out` block): `add_argument("--out-dir",
dest="out_dir", type=Path, default=None, help="папка вывода (создаётся при
необходимости); файл кладётся внутрь как <ориг-имя>.Encoded.<ext>. Взаимоисключающе с
-o/--out")`. `default=None` is mandatory (dispatch tests assert clean defaults).

**6. Thread `out_dir` through `_pipeline_one`** (`cli/main.py`): add
`out_dir=args.out_dir,` to the hand-built `encode_args = argparse.Namespace(...)`.
Without this, `enpipe run --out-dir X` silently drops the flag. The `detect_args`
Namespace does NOT get it (detection has no output-mux stage).

**7. Run batch branch** (`cli/main.py`): import `_ensure_out_dir` from
`enpipe.encoding.pipeline` (alongside the existing `resolve_output_path, run_encode`
import). Keep the existing run-batch `-o` guard; extend its message like the encode
side. After the guard block, compute `out_base = _ensure_out_dir(args)` once, and
change the run-batch `should_skip` closure's `resolve_output_path(v, args.out)` to
`resolve_output_path(v, out_base)`.

Do NOT touch overwrite semantics of the final muxed file.
