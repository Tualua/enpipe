## Accomplishments
- New cache-safe Dockerfile RUN layer downloads BtbN FFmpeg 8.1 GPL static, installs `ffmpeg`/`ffprobe` to `/opt/ffmpeg-8.1/bin`, and exposes them on PATH as `ffmpeg-8.1`/`ffprobe-8.1` (system ffmpeg untouched).
- Layer placed after the dovi_tool layer and before the final podman apt-sandbox-fix layer, so it does not invalidate the media/qsvencc/dovi_tool caches and the sandbox fix stays last.
- Russian WHY + pin-tradeoff banner documents the corruption-immune `av1_qsv` rationale (cross-process reference-surface aliasing in concurrent qsvencc — `.planning/debug/scene-chunk-frame-mismatch.md`), the `dovi_rpu` DV RPU passthrough that 6.1.1 lacks, and the deliberate acceptance of BtbN's moving `latest` tag (no SHA256).
- Non-fatal `post-create.sh` self-check reports ffmpeg-8.1 version + `av1_qsv`/`hevc_qsv` + `dovi_rpu`, guarded so it can never abort the script under `set -euo pipefail`.
