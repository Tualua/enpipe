<objective>
Два связанных изменения в devcontainer:

1. **claude-code через npm, а не через devcontainer-фичу.** Фича
   `ghcr.io/anthropics/devcontainer-features/claude-code:1` и так ставит
   npm-пакет `@anthropic-ai/claude-code` в nvm-префикс (проверено:
   `/usr/local/share/nvm/versions/node/v24.18.0/bin/claude ->
   ../lib/node_modules/@anthropic-ai/claude-code/bin/claude.exe`), поэтому
   переход на явный `npm install -g` в `post-create.sh` ставит claude рядом с
   opencode/qwen одной командой, убирает pin'ы из `devcontainer-lock.json` и
   снимает зависимость сборки от доступности ghcr.

2. **Авторизации claude / opencode / qwen переживают ребилд контейнера.**
   Сейчас все креды лежат в writable-слое контейнера и теряются при rebuild.
   Переносим их на named volumes.

Где именно живут авторизации (установлено осмотром работающего контейнера):
  - claude   → `$CLAUDE_CONFIG_DIR/.credentials.json` + `.claude.json`
               (OAuth-токен и `oauthAccount`/onboarding-состояние)
  - opencode → `/root/.local/share/opencode/auth.json`
  - qwen     → `/root/.qwen/settings.json` (`env.DASHSCOPE_API_KEY`), плюс
               `oauth_creds.json` для OAuth-режима

Проблема `.claude.json`: это ОДИН ФАЙЛ в `$HOME`, а named volume монтируется
только на каталог. Symlink на том — ловушка: claude пишет конфиг через
temp-файл + `rename()` (`saveConfigWithLock` в бинарнике), и rename ЗАМЕНИЛ БЫ
симлинк обычным файлом — персистентность молча перестала бы работать.
Поэтому используется официальный `CLAUDE_CONFIG_DIR`: эмпирически проверено
(`CLAUDE_CONFIG_DIR=<tmp> claude plugin list` → в `<tmp>` появились
`.claude.json` и `backups/`), что переменная переносит и config-каталог, и
`.claude.json`. Ставим её равной `/root/.claude` — тот же путь, что и по
умолчанию для каталога, но `.claude.json` переезжает ВНУТРЬ тома.

CANNOT be runtime-verified here: пересобрать контейнер изнутри него нельзя,
`docker`/`podman` недоступны. Все `verify` ниже — СТАТИЧЕСКИЕ (jq/grep/bash -n).
Рантайм подтверждает только чек-лист ребилда на хосте в конце плана.
</objective>
