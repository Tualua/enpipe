Точная семантика:
- frames.packet_table(path, cache_dir=None) -> Tuple[List[float], Tuple[int, ...]]: один вызов
  ffprobe (тот же argv, что у таблицы pts, но `-show_entries packet=pts_time,flags`), разбор построчно:
  первое поле — pts_time (N/A → прежняя ошибка про .obu/контейнер, нечисловое → прежняя ошибка),
  второе — флаги (ключевой, если в них есть «K»; второго поля нет — не ключевой). Пары (pts, ключевой)
  сортируются по pts (стабильно); индексы ключевых — позиции в отсортированной таблице (порядок
  показа). Кэш JSON версии 2: {"v": 2, "key", "pts", "keyframes"}; _read_cache принимает кэш, только
  если keyframes — список целых (не bool), строго возрастающий, каждый в [0, len(pts)); иначе
  пересчёт. frames.pts_table(path, cache_dir) возвращает packet_table(...)[0] (внешний контракт и
  вызывающие не меняются).
- precheck.scenes_reasons(scenes, n_src) -> List[str] (чистая): причины в порядке: (1) «.scenes: сцены
  не отсортированы» — если у какой-то сцены конец меньше начала или начало следующей меньше начала
  предыдущей; (2) «.scenes: сцены не идут подряд: сцена {i} кончается на кадре {e}, следующая
  начинается с кадра {s}» — первое расхождение e_i ≠ s_{i+1}; (3) «.scenes: первая сцена начинается с
  кадра {s0}, а не с 0»; (4) «.scenes: последняя сцена кончается на кадре {e}, в источнике {n_src}
  кадров». Сцены нулевой длины (s = e) допустимы.
- precheck.keyframe_reasons(scenes, offset, n_enc, enc_keyframes) -> List[str] (чистая): кадры
  энкода s − offset для различных начал s в [offset, offset + n_enc), по возрастанию; не входящие в
  set(enc_keyframes) — в одну причину «.scenes не совпадают с энкодом: начала сцен не на ключевых
  кадрах энкода (кадры энкода): a, b, …[, … и ещё N]; нужен .scenes, по которому шёл энкод, либо запуск
  без .scenes (склейки не проверяются)»; список не длиннее _KEYFRAME_LIST_MAX = 10 (константа модуля).
- precheck.check_pair(src, enc, src_pts, enc_pts, offset, scenes, cfg, *, enc_keyframes=None):
  позиционные параметры не меняются. Если scenes непусты и таблица pts источника без причин —
  reasons += scenes_reasons(scenes, len(src_pts)). Сверка ключевых кадров — только если scenes
  непусты, scenes_reasons пуст, у обеих таблиц pts нет причин и check_offset не дал причин (окно
  энкода определено): enc_keyframes is None → причина «сверка .scenes с энкодом невозможна: нет флагов
  ключевых кадров энкода», иначе reasons += keyframe_reasons(scenes, K, len(enc_pts), enc_keyframes).
  Работает и при полном энкоде (K = 0).
- pair.check_pair_files: для обеих сторон брать (pts, ключевые) из frames.packet_table одним
  вызовом; передавать enc_keyframes= флаги энкода в precheck.check_pair.

Выбор планировщика (reversible): None-флаги при непустых .scenes — отказ, а не пропуск сверки
(fail-closed; вызовов без флагов в src после правки нет). Сверка ключевых кадров пропускается при
