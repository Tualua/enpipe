Суть дефекта: склейка меряется кадрами start−1 (последний кадр ПРЕДЫДУЩЕГО чанка) и start (первый
кадр своего). combine_junction сводит их в одну точку, и «неопределённо» склейки не говорит, какая
сторона была неоднозначна. 10-15 разрешил закрывать склейку повтором только внутри [start, следующая
склейка) — это проверяет чанк ПОСЛЕ склейки. Если неоднозначен был только start−1, повтор в своей
сцене закрывает склейку, хотя предыдущий чанк не проверен: сдвиг предыдущего чанка со статичным
хвостом даёт ложное «выровнено» (зонд 10-REVIEW.md, воспроизведён верификацией).

  (start−1, start); для start = 0 и обычной точки — кортеж из одной точки.
- Сводная точка не «неопределённо» → итог как раньше (оба «выровнено» → «выровнено»; любой «сдвиг» →
  «сдвиг»).
- Иначе открыты стороны, чья половина не «выровнено» без ошибки. Сторона start — всегда своя
  половина; сторона start−1 — только при start > 0.

  никакую сторону не закрывает (WR-09).

  итог цели. Иначе → (исходная сводная «неопределённо», закрывающие повторы, голоса замен): закрывший
  одну сторону повтор засчитывается голосом, как голос замены (WR-09), но цель не закрывает. Это
