   смысла, не skip).

   `pts, keys = frames.packet_table(out)`; n_enc = len(pts) == scenes[-1][1]. Границы окна [0, n_enc):
   нижняя = число различных начал непустых сцен окна; верхняя = Σ ceil((min(e, offset+n_enc) − s) / 48) по
   непустым сценам окна. Утверждения: нижняя ≤ len(keys) ≤ верхняя; len(keys) < n_enc;

   w2 --from 1 --to hi --no-audio --no-metrics --jobs 2`. Для part те же границы на окне [offset, offset +
   n_part), `keyframe_reasons(scenes, offset, n_part, keys_part) == []`, len(keys_part) < n_part;
