### 5. Одночанковый режим: wmv3 без pts (полный файл)
У всех видеопакетов `wmv_test4.wmv` `pts_time=N/A`, поэтому файл кодируется одним чанком `--avsw` без детекта сцен (решения оператора, 10.1-13). Длинный прогон запускает оператор.

```bash
WMV=/data/downloads/wmv_test4.wmv
OUTD=$(mktemp -d)
cd /workspaces/enpipe && uv run enpipe run "$WMV" -o "$OUTD/wmv_test4.av1.mkv" --scenes "$OUTD/wmv_test4.scenes" 2>&1 | tee "$OUTD/wmv.log"; echo "rc=${PIPESTATUS[0]}"
grep -E "декод:|режим: один чанк|кадров декода источника|контейнер источника|склейка:|аудио:|ГОТОВО" "$OUTD/wmv.log"
ffprobe -v error -select_streams v:0 -count_packets -show_entries stream=nb_read_packets -of csv=p=0 "$OUTD/wmv_test4.av1.mkv"
mkvmerge --identify "$OUTD/wmv_test4.av1.mkv"
ls "$OUTD"
```

expected: `rc=0`; `декод: sw (wmv3 нет среди аппаратных декодеров GPU; --decode auto)`; одна строка `режим: один чанк на весь файл — у всех 43399 видеопакетов источника нет pts (pts_time=N/A); сценовая нарезка выключена: …`; `контейнер источника (Windows Media (ASF/WMV)) mkvmerge не читает; субтитров, глав и вложений в нём нет — источник в мукс не добавляется`; `кадров декода источника: N` и `склейка: N кадров (совпало с числом кадров декода источника)` с одним и тем же N (ожидаемо 43399, замер планировщика 10.1-13; расхождение с 43399 при совпадении N оценивает оператор); число пакетов выхода = N; `аудио: готово` (wmapro → Opus); mkvmerge видит AV1 и аудио; файла `wmv_test4.scenes` в `$OUTD` нет.
