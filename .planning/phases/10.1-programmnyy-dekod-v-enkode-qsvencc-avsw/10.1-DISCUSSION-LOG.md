## Когда включать --avsw

| Option | Description | Selected |
|--------|-------------|----------|
| Авто по коду из ffprobe | Список HW-кодеков GPU, кодек не из списка — --avsw, один раз на файл | |
| Только явный флаг | Оператор указывает --sw-decode, без флага VC-1 падает с подсказкой | |
| Авто плюс флаг-переопределение | Авто + флаг принудительного --avsw/--avhw | ✓ |
| Пробный запуск с откатом | --avhw на первом чанке, при rc 225 — --avsw | |

**User's choice:** Авто плюс флаг-переопределение

| Option | Description | Selected |
|--------|-------------|----------|
| Спросить у qsvencc при запуске | --check-features, разбор секции декодеров, при непонятном выводе — отказ | ✓ |
| Вшитый список в коде | Константа h264/hevc/av1/vp9/mpeg2 | |
| Список только для --avsw | Вшитый короткий список SW-кодеков | |

**User's choice:** Спросить у qsvencc при запуске

| Option | Description | Selected |
|--------|-------------|----------|
| --decode auto\|hw\|sw | Один флаг, дефолт auto | ✓ |
| --sw-decode / --hw-decode | Два флага | |
| Переменная окружения DECODE | Как ICQ/JOBS | |

**User's choice:** --decode auto|hw|sw

| Option | Description | Selected |
|--------|-------------|----------|
| Громкий отказ с подсказкой | die() до первого чанка | ✓ |
| Тихо на --avhw с предупреждением | Как сейчас | |
| Запасной вшитый список | Константа для B50 + предупреждение | |

**User's choice:** Громкий отказ с подсказкой (опрос не сработал в auto)

## Детект сцен для таких файлов

| Option | Description | Selected |
|--------|-------------|----------|
| Одно решение на весь файл | --decode управляет детектом и энкодом | ✓ |
| Детект и энкод независимо | Свои флаги у каждой стадии | |
| Детект не меняем | --no-qsv вручную | |

**User's choice:** Одно решение на весь файл

| Option | Description | Selected |
|--------|-------------|----------|
| Оставить как синоним --decode sw | Устаревший, конфликт с --decode hw — ошибка | ✓ |
| Убрать, только --decode | | |
| Отдельный флаг только детекта | | |

**User's choice:** Оставить как синоним --decode sw

Вопрос про чересстрочные/pulldown-источники. Пользователь сначала спросил: «А что делать, если нужно закодировать чересстрочное видео?» Пояснено: сейчас enpipe интерлейс не поддерживает ни на одном пути; деинтерлейс/bob/IVTC в qsvencc есть, но bob и IVTC меняют число кадров и ломают инвариант номеров кадров сцен — это отдельная фаза (записано в Deferred). Затем вопрос задан заново:

| Option | Description | Selected |
|--------|-------------|----------|
| Отказ только на пути --avsw | Новый путь защищён, --avhw как сейчас | |
| Отказ на любом пути | Проверка и для --avhw; меняет поведение для старых интерлейс-источников | ✓ |
| Не проверять | Как сейчас | |

**User's choice:** Отказ на любом пути
**Notes:** Политика для отсутствующего field_order не обсуждалась — вынесена в CONTEXT как открытый вопрос на решение оператора при планировании.
