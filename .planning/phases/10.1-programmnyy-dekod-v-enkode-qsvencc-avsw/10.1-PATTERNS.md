## Pattern Assignments

### `src/enpipe/shared/decode.py` (utility, листовой гейт)

**Analog:** `src/enpipe/shared/qsvencc_version.py` (parse-функция + функция-гейт с `die()`).

**Модульная шапка / импорты** (стр. 1-42 docstring "why"; ~44-52 импорты):
```python
from __future__ import annotations

import re
import subprocess
from typing import Optional

from enpipe.shared import proc as _proc
from enpipe.shared.logging import die
```
Модуль листовой: `encoding/pipeline.py` и `cli/main.py` оба его импортируют; решение в `detection` передаётся значением (`"hw"|"sw"`), импорта `detection` -> `encoding` нет. Docstring в начале на русском, с "why" (fail closed, без обхода, без пробных запусков).

**Parse-функция fail-closed** (`parse_revision`, ~стр. 79-90): чистая, `Optional` при неожиданности:
```python
def parse_revision(text: str) -> Optional[int]:
    for line in text.splitlines():
        line = line.strip()
        if line:
            m = _REV_RE.match(line)
            return int(m.group(1)) if m else None
    return None
```
Для `parse_decode_table` скопировать проверенную реализацию из RESEARCH.md (раздел "Опрос декодеров", привязка токена ячейки к ближайшему заголовку с допуском <= 2, ничья -> `None`). Типы только `typing` (`Dict`, `Tuple`, `Optional`).

**Вызов внешнего процесса + fail closed** (`ensure_qsvencc_fixed`, ~стр. 93-124):
```python
try:
    r = _proc.run(["qsvencc", "--version"], capture_output=True,
                  text=True, timeout=10)
except (OSError, subprocess.TimeoutExpired) as e:
    seen = f"{type(e).__name__}: {e}"
else:
    output = (r.stdout or "") + (r.stderr or "")
    ...
    if r.returncode == 0:
        revision = parse_revision(output)
    else:
        seen = f"{seen} (код возврата {r.returncode})"
if revision is None or revision < QSVENCC_MIN_REV:
    die(f"qsvencc не прошёл проверку версии: «{seen}»; ...")
```
Отличия для `query_hw_decoders`: `["qsvencc", "--check-features"]`, `timeout=30`, парсить **только `r.stdout`** (stderr шумный, rc=0 при "failed to allocate memory"), `die(... "задайте --decode hw или --decode sw")` на OSError/Timeout/rc!=0/нет секции/пустая таблица (D-04). Нет вшитого запасного списка.

**ffprobe-проба кодека/pix_fmt/field_order:** образец вызова `probe_fps` (`encoding/pipeline.py:94-106`):
```python
cmd = ["ffprobe", "-v", "error", "-select_streams", "v:0",
       "-show_entries", "stream=avg_frame_rate,r_frame_rate",
       "-of", "json", str(src)]
data = json.loads(_proc.run(cmd, capture_output=True, text=True, check=True).stdout)
st = data["streams"][0]
```
Взять `-show_entries stream=codec_name,pix_fmt,field_order -of json` и `st.get("field_order")` (именно `-of json`, не csv: иначе придёт строка `unknown`; см. `analysis/frames.py:155-160,194` `field_order=_tag(st.get("field_order"))`). Не импортировать `analysis` из `encoding`/`shared` - повторить минимальный вызов. Политика `None` для `field_order` - `checkpoint:decision` оператора (RESEARCH.md, варианты а/б/в); существующий аналог (а): `analysis/precheck.py:350` `if info.field_order is not None and info.field_order != "progressive":`.

**Кэш:** `ensure_qsvencc_fixed` намеренно без кэша; для опроса декодеров кэш допустим (решение планировщика). Если `functools.lru_cache`, то `cache_clear()` в autouse-фикстуре тестов.

**Лог D-12:** `from enpipe.shared.logging import log` - `log("декод: sw (vc1 нет среди аппаратных декодеров GPU; --decode auto)")`.

## Shared Patterns

### Fail-closed + `die()` на главном потоке
**Source:** `src/enpipe/shared/qsvencc_version.py` (`ensure_qsvencc_fixed`), `src/enpipe/shared/logging.py` (`die`, `log`)
**Apply to:** `decode.py`, preflight в `run_encode`/`run_pipeline`/`run_detect`. Любая неожиданность (rc, timeout, формат, неизвестный pix_fmt/кодек) - `die()` с русским текстом и подсказкой; без догадок и запасного списка. Воркеры `die()` не вызывают.

### Subprocess только через `enpipe.shared.proc`
**Source:** `from enpipe.shared import proc as _proc`; `_proc.run(cmd, capture_output=True, text=True, timeout=..., check=...)`
**Apply to:** опрос `qsvencc --check-features`, ffprobe-проба. Никакого прямого `subprocess.run/Popen` (в тестах-харнессе `_chunk_content.py` прямой `subprocess.run` допустим - это тестовый код).

### Одно решение на файл, передача значением
**Source:** `cli/main.py::_pipeline_one` (Namespace в обе стадии)
**Apply to:** `main.py`, `detection/pipeline.py`, `encoding/pipeline.py`. Разрешённое `"hw"|"sw"`; `auto` разрешается только в точке входа.

### Конвенции файла
`from __future__ import annotations`; `typing` генерики (`Dict/List/Optional/Tuple`), не `list[...]`; модульный docstring с "why" на русском; все сообщения/комментарии на русском; Ruff F/E9; импорт `from enpipe.shared.logging import die, log` (не `import logging`).

### Тесты
Быстрый тир `-m "not hardware"`, `--import-mode=importlib`, `--strict-markers`; hardware-тесты через маркер `hardware` и skip-гейт; мок subprocess - фикстура `fp`; env-константы модуля меняются `monkeypatch.setattr` на модуле.
