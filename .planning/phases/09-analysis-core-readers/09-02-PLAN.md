    Функции этой задачи:
    - `tile_edges(n, tile)` — алгоритм RESEARCH Pattern 2: `full, rem = divmod(n, tile)`; rem==0 → ровные тайлы; `full == 0` → `[(0, n)]`; `rem < tile / 2` → последний полный тайл растягивается до n; иначе отдельный тайл `(full*tile, n)` (граница «ровно половина» → отдельный тайл, D-08). n <= 0 или tile <= 0 → AnalysisError.
    - `mse(a, b)` — разность через `a.astype(np.int64) - b.astype(np.int64)` (защита от заворота uint16, Pitfall 4), среднее квадрата во float64, возврат `float`.
    - `psnr(a, b)` — `inf` при mse == 0, иначе `10*log10(PEAK_10BIT**2 / mse)`; приватный хелпер `_psnr_from_mse(m)` переиспользуется тайлами.
    - `pq_nits(code)` — формула прототипа на константах config: `e = clip((code - LUMA_BLACK) / LUMA_RANGE, 0, 1)`, `p = e**(1/PQ_M2)`, `PQ_PEAK_NITS * (max(p - PQ_C1, 0) / (PQ_C2 - PQ_C3*p))**(1/PQ_M1)` (D-11).
    - `lap_energy(y)` — `mean(|4·c − 4 соседа|)` по внутренней области; `h < 3 or w < 3` → None (Pitfall 3).
    - `luma_tiles(sy, ey, cfg)` — сетка `tile_edges(H, cfg.tile_y)` × `tile_edges(W, cfg.tile_y)`; худший = минимальный PSNR (максимальный MSE); при равенстве — первый в растровом порядке (y, затем x) для детерминизма; возвращает `LumaTile(x, y, w, h, psnr)` в пикселях Y.
    - `chroma_tiles(su, sv, eu, ev, cfg)` — сетка по плоскости цветности с `cfg.tile_c` (считается независимо от Y, НЕ делением границ Y пополам — RESEARCH Pattern 2); худший — максимум `mse_u + mse_v` (D-09), ничья — первый в растровом порядке; координаты и размеры ×2 в пиксели Y; возвращает `ChromaTile(x, y, w, h, psnr_u, psnr_v, mse_uv)`.
    - `luminance_stats(sy, cfg)` → `(float(nits.mean()), float((nits < cfg.shadow_nits).mean()))` (D-11).
    - `detail_preservation(sy, ey, cfg)` — глобально `lap(ey)/lap(sy)`; если `lap(sy)` None или `< cfg.detail_eps` → глобальное None (плоский источник — сохранять нечего; решение Pitfall 2, документировать комментарием).
